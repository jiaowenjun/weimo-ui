验证步骤

  1. 模式 A 下,在左侧列表里缓慢拖动或斜向滑动(往右下/右上斜)→ 预期:第一次常常完全不滚,第二次快速垂直划才滚。日志里红 P 帧出现 = touchmove 被 preventDefault。
  2. 同一划法切到模式 B → 预期:第一次立即跟手。证明根因 = capture 层 preventDefault。
  3. 切到模式 C(列表根节点加 data-base-ui-swipe-ignore,Base UI 官方逃生门)→ 预期:与 B 等价,第一次即跟手。

每帧标记:P = 本帧被 preventDefault;S = 纵向位移≥6px 逃生门生效,本帧起放行;I = swipe-ignore 命中,直接放行。判定链与 Base UI 1.5.0 DrawerViewport 一致。
